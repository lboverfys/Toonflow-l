# Sub2API 生图扩展

从便携版 2.0.2 起，Sub2API 生图作为内置媒体供应商自动安装，已有的模型列表及配置保留。旧版仍可通过自定义媒体供应商入口导入 `sub2apiImage.ts`，无需重新打包。默认站点为 `https://yuzapi.fun`，预置 `gpt-image-2.5-sunburst` 与 `gpt-image-2.5-flare`。

## 导入与调整

1. 打开「设置 → 媒体模型」，找到「Sub2API 生图」。
2. 若此前删除了它，可通过「添加供应商 → Sub2API 生图」重新添加；旧版使用「添加自定义供应商 → 文件导入」导入 `sub2apiImage.ts`。
3. 打开该供应商的「编辑模型」，填写本站点签发的 API Key 并保存。
4. 在画布图片生成节点中选择「Sub2API 生图」下的模型；文本 AI 也能通过媒体模型查询工具找到它。

密钥仅填写在应用设置中，不写入扩展源码、说明或聊天。扩展不会读取或复制 Codex skill 的配置。

供应商配置均可手动修改：

| 设置 | 初始值 | 调整方式 |
| --- | --- | --- |
| API 地址 | `https://yuzapi.fun` | 可改为自己的 HTTPS 地址，支持根地址或 `/v1` |
| API Key | 空 | 填写该站点签发的密钥 |
| 品质 | `max` | 可选 `auto`、`low`、`medium`、`high`、`xhigh`、`max` |
| 图片格式 | `png` | 可选 PNG、JPEG、WebP |
| 自定义像素尺寸 | 空 | 留空跟随节点；填写 `2048x1152` 等像素值或 `auto` 后，优先于节点的尺寸与比例 |
| 单次请求超时 | 300 秒 | 可改为 1～3600 的整数秒 |

模型列表使用 Toonflow 原有的模型编辑器，模型 ID、显示名、尺寸与比例选项均可编辑。扩展不会限制只能使用两个预置 ID；新增或改名后的型号须由站点提供，并使用相同图片协议。尺寸校验按 GPT Image 2/2.5 规则执行，其他协议或尺寸规则的模型需要另行适配。

品质、格式、自定义尺寸和超时是此供应商的公共配置；画布节点可分别选择模型、尺寸与比例。当前画布和文本 AI 的媒体工具没有单独的品质输入，调整品质请到供应商设置。

## 尺寸

画布的预置档位转换为以下实际请求尺寸，不对返回图片放大、压缩或转码：

| 比例 | 1K | 2K | 4K |
| --- | --- | --- | --- |
| 1:1 | 1024x1024 | 2048x2048 | 不支持此组合 |
| 3:2 | 1536x1024 | 2304x1536 | 不支持此组合 |
| 2:3 | 1024x1536 | 1536x2304 | 不支持此组合 |
| 16:9 | 1536x864 | 2048x1152 | 3840x2160 |
| 9:16 | 864x1536 | 1152x2048 | 2160x3840 |

需要其他尺寸时，在供应商的「自定义像素尺寸」中填写，或将有效像素值添加到模型的尺寸选项中；像素值本身确定画幅。`auto` 由上游自行选择尺寸，不保证节点中选择的比例。

宽、高须为 16 的倍数，单边不超过 3840，宽高比在 1:3～3:1，总像素在 655360～8294400。方图最大可填写 `2880x2880`；`4096x4096`、`3840x3840`、`1920x1080` 不符合这组规则。非法组合在请求前报错。

## 调用与边界

- 文生图：`POST /v1/images/generations`，发送 JSON。
- 参考图编辑：`POST /v1/images/edits`，以 multipart 的 `image[]` 字段按原顺序上传原图；蒙版使用 `mask`。
- 认证：`Authorization: Bearer ...`；仅生成请求携带密钥，图片链接下载不携带该密钥，不跟随重定向。
- 固定单次一张、`stream: false`，接受 `data[0].b64_json`、`image_base64` 或 `url`。原图按实际格式回填并保存到 Toonflow 工作区。
- 参考图单张最多 20 MiB，参考图与蒙版合计最多 50 MiB；输出图片最多 50 MiB。支持 PNG、JPEG、WebP；蒙版须为与第一张参考图同尺寸的 PNG。
- 使用同步接口，无可恢复的任务编号，不自动重试。超时、断线或下载失败不代表上游未生成；重新生成前先核对站点记录，避免重复消耗额度。
- 本扩展不依赖异步任务对象存储，也不修改 sub2api 服务端。

调用方式参考本机 `lboverfys-gpt-image` skill，并对照 `D:\Happy\sub2api` 的 `dev_wecoding` 分支提交 `17693bc9e`。站点是否部署该版本、密钥的分组权限、实际支持的模型与费用，仍以 `https://yuzapi.fun` 的运行配置为准。
