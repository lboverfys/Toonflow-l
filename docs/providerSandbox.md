# 供应商子进程执行设计（T31）

状态：已完成调用边界分析，尚未实施子进程迁移。当前仍使用 `node:vm`，只允许本机页面管理供应商。子进程本身不限制文件、网络或当前用户权限，不能当作操作系统沙箱。

## 需要保持的接口

`loadMediaProviderSource` 返回供应商元数据与运行方法。调用方包括供应商调试、模型刷新、媒体生成及断点恢复。迁移必须覆盖这些入口，不能只隔离调试面板。

供应商通过 `this.tool` 使用以下能力：

| 能力 | 拟定执行位置及协议 |
| --- | --- |
| 源码解析、模块求值、`processMedia` 与生成方法 | 子进程。接收本次源码、配置和输入，不开放任意模块导入。 |
| `hash`、`sha256`、`Bun.Image`、内存图片处理 | 子进程本地。保留同步调用和类实例行为，不把对象序列化为普通 JSON。 |
| `fetch` | 由宿主转发请求头、流式响应和取消，保留调试记录、错误提取及脱敏；禁止一次性缓冲任意大小响应。 |
| 图片与视频任务、参考素材缓存、视频下载 | 宿主。沿用已有锁、操作 ID 和原子写入，避免多个进程同时读写配置或任务记录。 |
| FFmpeg 工厂、链式方法、事件与回调 | 需要专门的对象句柄协议，普通 Promise RPC 无法替代当前接口。不能直接删除这些接口或把文件访问转交无边界的子进程。 |
| 最终媒体结果 | 二进制有界传输，文件结果由宿主签发；不得接受子进程直接返回任意磁盘路径。 |

## 最小生命周期

每次调用绑定一个执行进程和取消信号。宿主按调用 ID 分发能力请求，只接受已登记的方法。正常结束关闭通信并回收进程；取消时先取消宿主网络、文件和 FFmpeg 操作，等待已开始的落盘收尾，再终止执行进程。异常退出必须向原调用方报告失败，保留已经受理的远端任务记录，不能自动重新提交付费生成。

桌面打包、独立 server 和 Android 必须把子进程入口作为单独资源分发，并验证启动路径、执行权限和 Android 进程能力。生产构建不能依赖源码目录或开发依赖。

## 当前未完成原因

现有接口包含同步 `Bun.Image` 类、流式 `Response`、FFmpeg 方法链和宿主签发的文件对象。它们不能直接通过 JSON/结构化克隆保持行为。当前环境缺少模型凭据和 Android、macOS 真机验证条件，无法完整验证取消、任务恢复及媒体对象传递。为避免交付仅覆盖部分入口或破坏已受理任务的迁移，本次保留现有执行方式，后续需要完成上述协议后再切换。

验收应覆盖真实供应商的图片、音频、视频、调试流、模型刷新、取消与恢复；同时验证执行进程崩溃、超时与应用退出后不存在残留进程。操作系统权限隔离需要独立设计和各平台验证，不能由“迁移到子进程”这一改动宣称已经实现。
