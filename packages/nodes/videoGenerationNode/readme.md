# 视频生成节点

根据提示词和参考素材生成视频，支持所选模型提供的文生视频、单图、首尾帧或混合参考模式。

## 输入与输出

- 输入支持文本、图片、视频和音频，实际可用的素材组合取决于模型与生成模式。
- 输出生成的视频；播放器还能将当前帧、首帧或尾帧截取为图片节点。

## 使用方法

1. 选中节点，选择视频模型；没有模型时先在设置中添加视频模型。
2. 输入动作、运镜和声音要求，按需连接参考素材并调整引用顺序。
3. 打开生成设置，选择模式、时长、分辨率和画面比例；模型允许时可切换“生成音频”。
4. 使用首尾帧模式时，图片按引用顺序分配；“首帧可选”模式仅有一张图片时，该图片作为尾帧。
5. 点击“生成视频”，需要中止时点击“停止生成”。
6. 完成后可播放、拖动进度、调整音量，或从上方下载和全屏预览。

截帧需要启用图片节点。时长与分辨率选项随模型变化，通用画面比例的实际支持范围由供应商决定。

## ZEALMAN-H3 U06 快捷生成

1. 在媒体供应商设置中填写 ZEALMAN-H3 的面板地址，并在面板启动 ComfyUI。
2. 选中视频节点，在右侧节点面板选择「ZEALMAN-H3 自部署 → H3 U06-V5」。同一侧栏会显示 U06 快捷设置，自动读取主模型、CLIP 和 LoRA 清单；清单变化后点击「刷新面板选项」。U06 使用快捷生成模板，无需填写 API 工作流 ID。
3. 选择主模型、编码器、加速 LoRA 和额外 LoRA，填写两组强度。不兼容的完整／剪枝 LoRA 会禁用；切换原版／加速会带入对应的采样步数，仍可手动修改。
4. 设置比例、具体分辨率、时长、步数和随机／固定种子。时长上限跟随面板，固定种子支持 15 位整数；可开启 VAE 前清理和支持当前显卡的 RTX 超清 2×。
5. 可连接或直接上传最多 9 张图片、3 段视频和 3 段音频，无素材时使用文生视频。图片保留原文件；视频按网页规则保持比例，短边最多 768、面积最多 1032192 像素并对齐 32。输入框的 `@` 标签对应 `<Picture N>`、`<Video N>` 和 `<Audio N>`。
6. 点击「生成」。生成期间可修改下一条参数并「加入队列」，节点逐条执行，数量上限跟随面板。每条保存加入时的提示词、设置和素材路径，排队期间请保留原素材文件。

队列随画布保存；重新打开后，已提交任务按原编号恢复，未开始的任务点击「继续队列」。失败会暂停后续任务；可移除未开始的条目。「停止等待」暂停队列和本地查询，不会取消远端已提交的生成。U06 任务会保存当次完整工作流和随机种子，恢复时不受后来修改的参数影响。

## H3 主体、对白与 Skill 优化

- 在素材卡下方给图片或视频中的主体取名；相同名称合并为一个主体。「音色与说话人设置」可将音频绑定主体与说话人编号，U06 还可选择并试听面板内置音色（与上传音频合计最多 3 段）。
- 点素材卡的「换位置」选择目标，或拖到同类素材上交换。图、视频、音频分别编号，正文标签、主体定义与生成时的素材顺序同步更新；撤销文字也会保持正确的素材对应关系。链接图片、上传音频、内置音色分别在各自来源组内交换。
- 图片、视频、音频、主体、对白和镜头用不同颜色的标签区分。点击主体标签可定位对应素材，点击图片标签可预览；「全屏编辑」展开同一份素材和提示词，点击「完成编辑」返回节点继续生成。
- 输入 `@` 选择素材、主体、说话人、对白、镜头、任务类型或六段标题。点击对白标签可修改台词；「插入对白」支持语气、语言、齐声、旁白、内心独白、跨镜与截断。
- 「标签 / 代码」切换显示方式；支持复制、清空、撤销与重做（Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z）。「插入骨架」按素材和时长生成六段结构，已有文字保留为创作需求。
- 「Skill 优化提示词」使用设置中已配置的文本模型，齿轮中可切换模型并查看 Skill 原文。系统提示词直接读取 `src/h3PromptSkill.txt`，原文不作删改；本次需求和素材映射作为用户消息传入。图片理解需所选模型支持看图，视频与音频以引用标签和用户描述传入。
- 优化成功会填回六段文本，并在模型上限内增加多镜头所需时长。格式错误、台词或关键标签被改动时不覆盖原文；优化期间素材发生变化时单独展示结果。可停止优化或撤销回到原提示词。
- 「面板素材库」可分页浏览、搜索、预览面板输入和历史输出，再导入当前项目。导入不会删除远端文件；画布素材继续通过 Toonflow 素材库和节点连线复用。
- H3 提示词编辑器也适用于 AutoDL MiniMax H3 全参考模型；内置音色、参考视频、面板素材库和 U06 参数仅在支持它们的 ZEALMAN-H3 U06 模型中提供。
