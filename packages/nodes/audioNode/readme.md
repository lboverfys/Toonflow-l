# 音频节点

将音频素材放到画布中试听，并提供给支持音频参考的下游节点。

## 输入与输出

- 导入本地音频文件，单个文件不能为空且不超过 100 MB。
- 输出当前音频素材，可连接支持音频输入的节点。

## 使用方法

1. 点击上传按钮，选择音频文件。
2. 上传完成后，使用节点内的播放器试听、暂停或调整播放进度。
3. 将音频输出连接到需要该素材的节点。
4. 需要换素材时，将鼠标移到节点上，点击“替换音频”。

## 从视频截取音频

1. 在视频节点点击“提取音轨”，再选中生成的音频节点，点击“截取”。
2. 拖动波形两端的边界，或输入开始、结束秒数；也可点击波形定位，再将当前位置设为起点或终点。
3. 点击播放按钮试听选中范围，播放到终点自动停止。边界支持方向键以 0.01 秒微调，Shift 加方向键以 1 秒调整。
4. 点击“导出选中片段”，只导出当前高亮片段。新节点名称标明原音频的起止时间；窗口保持打开，方便继续截取下一段。
5. 需要多段拼接时，在当前位置分割，删除不需要的片段，再点击“拼接导出全部”。片段列表显示每段的源时间和时长，导出按钮显示实际导出范围的总时长。

截取、分割与删除支持撤销和恢复。输出为 M4A/AAC，按音频采样裁剪并重新编码，原素材保持不变。
