# 视频节点

导入、播放视频素材，并将视频或截取的画面用于后续制作。

## 输入与输出

- 导入本地视频文件，单个文件不能为空且不超过 100 MB。
- 输出当前视频素材，可连接支持视频输入的节点。
- 截帧结果作为新的图片节点出现在画布中。

## 使用方法

1. 点击上传按钮选择视频，使用播放器播放、暂停、拖动进度或调整音量。
2. 将视频输出连接到需要参考视频的节点。
3. 点击“截取视频帧”，选择当前帧、首帧或尾帧；此功能需要启用图片节点。
4. 选中节点后，在右侧面板点击“替换视频”可更换素材。
5. 点击“预览视频”进入大屏预览；顶部可返回画布、关闭预览或进入全屏。播放结束后可重新播放或返回画布，Esc 逐层退出全屏和预览。
6. 桌面端预览期间点击应用关闭按钮，会先选择返回画布或退出应用；退出仍会执行原有保存检查。
